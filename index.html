ESTRUCTURA DE DATOS

COLAS

En programación, una cola (queue) es una estructura de datos que sigue el principio FIFO (First In, First Out): el primero en entrar es el primero en salir.

COLA SIMPLE

El primer dato añadido es el primero que se elimina, similar a una fila en una taquilla o supermercado.

COLA CIRCULAR

El último elemento se conecta con el primero para formar un anillo. Esto permite reutilizar el espacio de memoria liberado cuando se extraen elementos.

COLA DE PRIORIDAD

Los elementos se atienden según su valor de prioridad y no por el orden en que llegan. Si dos elementos tienen la misma prioridad, se utiliza su orden de llegada.

COLA DOBLE

Estructura de datos lineal que permite insertar y eliminar elementos por ambos extremos (frente y final). A diferencia de una cola simple, rompe la regla estricta de primero en entrar, primero en salir (FIFO)

OPERACIONES BASICAS

OPERACIONES BASICAS DE COLAS

  • Enqueue: insertar un elemento.
  • Dequeue: eliminar el primer elemento.
  • Front/Peek: ver el primer elemento sin eliminarlo.
  • IsEmpty: comprobar si está vacía.
